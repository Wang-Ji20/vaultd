# Roadmap

The long-term plan. Current work is tracked in [PLAN.md](PLAN.md).

## v1 (see SPEC.md)

- [x] Read-only vault over stdio
- [x] Real search
- [x] Shared HTTP endpoint with per-app tokens
- [x] Safe writes
- [x] Upstream proxy and audit log
- [ ] Admin portal
- [ ] OS service and release builds

## Not planned for v1

These are deliberate non-goals of the first version:

- Remote access for web or mobile apps.
- Semantic (embedding) search.
- Multiple users.
- Deleting or overwriting notes.
